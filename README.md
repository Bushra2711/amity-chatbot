# AI-Powered Student Support System for BCA Admissions 

An AI-powered chatbot developed using Flask and Machine Learning techniques to help students with Amity University BCA admissions, fees, scholarships, eligibility, placements, and specializations.

---

# Project Overview

The chatbot provides real-time responses using TF-IDF intent matching and supports both English and Hinglish communication. It is designed with a modern responsive dashboard UI and interactive specialization cards.

This project demonstrates:

* Artificial Intelligence concepts
* Natural Language Processing (NLP)
* Machine Learning intent matching
* Full-stack web development
* Responsive UI/UX design

---

# Features

* English + Hinglish language support

# Installation Steps

## 1. Clone or Download the Project

git clone https://github.com/yourusername/amity-chatbot.git

---

## 2. Create Virtual Environment

python -m venv .venv

Activate environment:

### Windows

.\.venv\Scripts\activate

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run the Project

python app.py


Open browser:

http://127.0.0.1:5000
